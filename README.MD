# Yaj Personal Site

A small personal site and browser-based project workspace.

## Pages

- `src/me/about_me.html` is the About page.
- `src/me/github_projects.html` lists open-source contributions, personal projects, and plans.
- `school/html-performance-task/page.html` is the reading page used for the HTML preview.

## Workspace

Open `page.html` to use the project tree, file tabs, source viewer, and rendered previews. HTML files open as previews from their parent folders. Other files open as highlighted source. `README.MD` opens as rendered Markdown.
